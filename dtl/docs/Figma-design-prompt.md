# Figma Design Prompt – General Auto Service Website (Simplified)

Use this prompt in Figma AI / FigJam or as a brief for a designer. Generates a **reusable template** for auto service sites. Excludes car wash and tyre service – only **general mechanical service**. Adapt for different clients by swapping brand name, colors, and copy.

---

## Prompt for Figma

```
Create a modern, professional website design for a generic auto service (car repair/mechanic) business. Use placeholder brand name "[BRAND]". The site offers ONLY general mechanical services (no tyre, no car wash). Target: local customers seeking repairs, maintenance, and diagnostics.

## Scope – INCLUDE
- General auto service: revisions, brakes, suspension, engine, computerized diagnostics
- Online booking for general service
- Quote request form
- Contact page with form, phone, email, WhatsApp, address, map
- Gallery
- Testimonials
- Client account – optional, can be shown as future state

## Scope – EXCLUDE
- Tyre service (mounting, balancing, tyre hotel, wheel alignment)
- Car wash service (washing, detailing, cosmetics)
- Any tabs or sections for tyre or car wash

## Pages to Design

### 1. Homepage
- Hero section: full-width image (auto workshop/mechanic), dark overlay, headline placeholder "[BRAND] – Complete solutions for your car", subtitle mentioning general service (revisions, brakes, suspension, engine, diagnostics)
- CTA: "Book appointment" (primary) + "View services" (secondary)
- Services highlight: ONE category – "General service" with wrench icon, 3–4 service items, link to Services, link to Booking
- "Why choose us?" section: 3 value props (genuine parts, transparency, modern equipment)
- Map & contact block: address, phone, email, working hours, map placeholder

### 2. Services
- Header: "Services" title, subtitle about mechanical services
- Single category: General service – image left/right, list of services with optional prices, CTA "Book appointment"
- Link to full services list

### 3. Booking
- Title: "Book an appointment"
- Single booking form (no tabs): date, time, name, phone, email, car make/model/year, service type (dropdown: Revision, Brakes, Suspension, Engine, Diagnostics, Other), optional description
- No tyre or car wash options

### 4. Request Quote
- Simple form: name, phone, email, car details, description of work needed
- CTA: "Submit request"

### 5. Contact
- Contact info cards: Phone, WhatsApp, Email, Opening hours
- Contact form: name, email, phone, message
- Map section (placeholder)

### 6. Gallery
- Grid of images (3–4 columns), lightbox-ready layout

### 7. Testimonials
- Card grid (2 columns desktop), each card: quote, author name, optional role, optional star rating

### 8. Header (Global)
- Top strip (primary color): phone, email, center link "View offer"
- Main nav (white): Logo placeholder "[BRAND]", links: Home, Services, Book, Request Quote, Contact, Gallery, Testimonials
- Sticky on scroll
- Mobile: hamburger menu, full-screen overlay

### 9. Footer (Global)
- Dark: logo, short description, useful links
- Contact: phone, email, address
- Opening hours
- Minimal, clean

## Design System

- **Typography**: Clean, readable. Headings bold/black, body regular. Geist, Inter, or similar.
- **Colors**: 
  - Primary: customizable (suggest blue #2563eb)
  - Backgrounds: white, light gray for sections
  - Dark sections: slate-900, slate-950
  - Text: dark for headings, medium gray for body
- **Spacing**: Generous padding, max-width ~1280px for content
- **Components**: Rounded corners (xl/2xl), subtle shadows, clear CTAs
- **Language**: Neutral/English – adapt to local language when cloning
- **Responsive**: Mobile-first. Breakpoints: mobile (<768px), tablet (768–1024px), desktop (1024px+)

## Style Direction
- Professional, trustworthy, modern
- Not playful – mechanic/repair business
- Clear hierarchy, easy navigation
- High contrast for accessibility
- Imagery: auto workshop, tools, mechanics, cars
```

## Generating Variants for New Websites

When creating variants for different clients, change:

| Element | Replace with |
|---------|--------------|
| `[BRAND]` | Client name (e.g. DTL Service, AutoMax, QuickFix) |
| Primary color | Client brand color |
| Hero headline | Client-specific tagline |
| "Why choose us?" | Client-specific value props |
| Logo | Client logo placeholder |
| Language | Romanian, English, or other (ro/en/etc.) |

### Example Variants

- **Variant A**: Blue primary, "[BRAND] Service Auto", Romanian copy
- **Variant B**: Green primary, "[BRAND] Garage", English copy
- **Variant C**: Orange/amber primary, "[BRAND] Auto Repair", German copy
